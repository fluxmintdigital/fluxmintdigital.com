    <h1>Link Restore</h1>
    <p class="semantic-lede">Make broken links behave like ordinary browser links again.</p>

    <div class="prose">
      <p>Link Restore is intended to restore expected browser behavior when websites interfere with common alternate link-opening interactions.</p>

      <section class="inside-the-work" aria-labelledby="link-restore-supported-heading">
        <h2 id="link-restore-supported-heading">Supported interactions</h2>
        <ul>
          <li>Ctrl-click or Cmd-click opens a link in a background tab.</li>
          <li>Ctrl/Cmd+Shift-click opens and focuses a new tab.</li>
          <li>Shift-click opens a link in a new window.</li>
          <li>Middle-click opens a link in a background tab.</li>
        </ul>
        <p><strong>Normal left-click behavior is not modified by Link Restore.</strong></p>
      </section>

      <section class="inside-the-work" aria-labelledby="link-restore-local-heading">
        <h2 id="link-restore-local-heading">Local by design</h2>
        <p>Link Restore observes qualifying interactions locally on ordinary HTTP and HTTPS webpages so it can provide its stated function. Settings stay in the browser, and the extension does not send browsing activity to FluxMintDigital.</p>
        <p class="semantic-lede">No account. No ads. No analytics. No browsing-history collection. Settings stay local.</p>
      </section>

      <section class="inside-the-work" aria-labelledby="link-restore-availability-heading">
