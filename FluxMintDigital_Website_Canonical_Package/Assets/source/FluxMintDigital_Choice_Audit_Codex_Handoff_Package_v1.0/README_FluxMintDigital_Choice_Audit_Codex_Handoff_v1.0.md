## Hard Constitutional Boundaries
The implementation must not:
- diagnose
- score
- rank
- generate personality interpretations
- claim causation
- infer meaning on behalf of the reader
- require completion
- force sequence
- convert qualitative marks into percentages
- remotely persist reflection content by default
- send reflection content to analytics, telemetry, URLs, logs, or error payloads
- place acquisition prompts inside the working field
- gate the free tool behind email/account/payment
- gamify completion
- rely on hover for required interaction
- use color as the sole carrier of state meaning

## Digital Constitutional Invariant
> **The interface may reveal structure, preserve evidence, and reflect what the person entered. It must not quietly become the authority that tells the person what their structure means.**
